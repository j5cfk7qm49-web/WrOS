# WrOS — Writer’s OS

WrOS is a planned **offline-first, bootable Linux writing operating system**, built around the Grimoire novel editor. It is intended for dedicated low-powered writing laptops, not just as a terminal application.

**Development status:** unfinished prototype. The recovered full source history **has not been imported into this GitHub repository yet**; the current `main` branch contains coordination documents only. Do not install on a production laptop.

- [Source import and recovery handoff](SOURCE_IMPORT_HANDOFF.md)
- [Issue tracker and engineering backlog](https://github.com/j5cfk7qm49-web/WrOS/issues)
- [Official branding and compatibility migration issue #14](https://github.com/j5cfk7qm49-web/WrOS/issues/14)

The former working title was “WritingDeck OS.” Some preserved historical Git branches and technical identifiers still contain `writingdeck`; those must be migrated carefully without rewriting history or breaking compatibility. Grimoire remains the core editor, with its original upstream attribution and notices.
