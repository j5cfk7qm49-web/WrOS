Production installer/LUKS/first-run/authentication/lock-before-suspend; custom layout registration/onboarding and remaining sound/clock/timezone controls; signed boot/update/recovery/rollback and authenticated maintenance; real gross/net/deleted/active/idle/drafting/revision/footnote edit-ledger accounting and richer journal analyses; November calendar/advanced goals/challenges/achievements; actual 1,000-option licensed Spark corpus; Harper/Nabokov/proselint/WordNet; continuity/annotations/variants; genuine bottom-page DOCX/PDF footnotes; verified off-device/Drive restore/mobile/Docs workflows; all 39 complete exercises; physical keyboard/Wi-Fi/suspend/battery, kernel power-cut and large-note/card/log/analyzer performance qualification. Wi-Fi scan truncation/enrollment is not fixed or qualified by M4c.

Metadata/ownership/fingerprint guards are **not OS locks, cross-process CAS, hostile-filesystem-race defense, cross-file atomicity, a durable per-edit ledger or backup**. Journal observations are sampled and pending facts are memory-only; crash/explicit forced exit can lose them. Controlled Prepared/completion I/O tests are not real power-loss experiments. Large-document/index/log latency, idle/input CPU and flash-write budgets remain unqualified.

**VM-only security warning:** passwordless tty1 autologin, locked passwords, unsigned bootloader and a probe that powers off the guest. Never install this demo onto a real laptop or treat it as recovery-capable production software.
