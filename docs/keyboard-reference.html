WRITINGDECK · OFFLINE REFERENCE · 0.1.0-DEV

Your keys, your writing desk.

QWERTY · Colemak · Colemak-DH — use the logical key label after Linux layout translation. Print from your browser.

F12 home   F10 outline   Ctrl-D strict focus.
F11 is not yet an editable second pane. System → Keyboard layout has a 15-second preview: Enter keeps it, Escape/timeout reverts it. System → Keyboard shortcuts adds safe Ctrl+Alt+A–Z or F10–F12 aliases; legacy keys stay available. Avoid AltGr conflicts. No double remapping.

Ctrl can be Cmd wherever your terminal sends it.

Help

Type to search every topic. Esc clears the search, then closes the help. In a narrow window the article has the whole box, and Esc steps back from it to the topics first.

Generated from assets/help/24-every-key.md. Plain-text searchable help is built in (F1). Some terminals cannot distinguish Ctrl-I/Tab or Ctrl-M/Enter; use menu/palette alternatives. Optional music needs its own setup; writing never needs a network. This foundation is not a production installation.
