# Scratchpad

Scratchpad is a collection of ordinary original Notes, not a parallel manuscript editor or generated idea service. Open Scratchpad in Ctrl-K, Writing tools or dashboard s. Each original lives in notes/scratchpad; the separate guarded workflow index stores references, scene links, lifecycle and promotion receipts, never note prose.

| Key | Action |
| --- | --- |
| Up / Down | Select an original note |
| n / N | Explicit new original in Secondary / Primary |
| Enter / e | Edit the selected original in Secondary / Primary |
| l | Choose a real manuscript scene to link; no file is moved |
| g | Open the linked original manuscript scene |
| p / v | Promote the saved idea / open its independent original scene |
| x | Cancel only an unwritten preparation; never deletes a target |
| Tab | Active / archived / trashed references |
| a / Delete | Archive or restore / Trash reference; never delete its original |
| PgUp / PgDn, Home / End | Scroll this preview only |
| r | Explicitly reload metadata/source references |
| Esc | Leave reader |

Save genuine prose and link a scene before promotion. Promotion keeps every byte of the original note, retains Markdown/unknown YAML in the new scene and explicitly enables compile only in that new scene. This is an intentional independent snapshot: later edits do not synchronize. Repeated p does not duplicate or overwrite a ready scene. A moved/deleted ready target is not recreated.

A prepared receipt is guarded and saved before a create-new destination is written. If completion fails, both original and any target remain; r then p retries that same target without replacing a competing version. This is recoverable multi-file work, not an atomic filesystem-wide transaction or power-loss certificate. An exact existing prepared target can finalize even if the separate original has since changed. A changed target is never replaced. If an unwritten prepared source has changed, x cancels only that unwritten intent, so an explicit new p can use the newly saved original; no file is deleted. A failed new-note creation can retain an unavailable reserved reference; restore that original path or make another note. Missing originals are not recreated from previews.

Strict focus hides Secondary: leave it with Esc then Ctrl-D, or explicitly use N/e for Primary. Existing original owners keep their undo, selection and cursor; ambiguous aliases/unsettled/non-UTF-8 sources are refused. Dirty/Waiting saves and ownership failures cannot create a competing body. Reader paste/typing is not prose; bracketed/clipboard paste is ignored. Read-only rendering does no file or command I/O. Notes remain excluded from manuscript totals until an explicit promoted scene exists. No gross typing/time estimate is invented.

Promotion retains Markdown content with normal frontmatter separation; relative resource destinations are not rebased. Review those links in the independent scene before publication. Root/bare-name wiki links still refer to their existing originals; the note itself is never moved.
