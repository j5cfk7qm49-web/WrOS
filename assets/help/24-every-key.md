# Every key

`Ctrl` can be `Cmd` wherever your terminal sends it.

## Everywhere

| Key | Does |
|---|---|
| `Esc` | the menu — or first, closes a note or scene beside, or lets go of a selection |
| `F1` | this help, on the topic for where you are |
| `?` | this help too, wherever you aren't typing; on the page it's a question mark |
| `Ctrl-K` | find anything: actions, scenes, notes, themes |
| `Super` tap | open Find anything beneath the menu bar |
| `Super+1` | switch to Write |
| `Super+3` | switch to Brain |
| `Super+4` | open Review cards |
| `Tab` | the next pane; `Shift-Tab` the one before |
| `Ctrl-S` | save now (autosave already does) |
| `Ctrl-Q` | quit in a desktop session; installed WrOS keeps the writing app open |
| `Ctrl-Z` | undo: typing in the page; a delete, rename, move or new item in the outline |
| `Ctrl-Y` | redo |
| `Ctrl-F` | find in the scene; again for the whole project |
| `Ctrl-D` | focus mode |
| `Ctrl-V` | paste, from the computer's clipboard |
| `Ctrl-A` | select the whole scene |
| `Ctrl-B` | bold on the selection or the word at the cursor, or off again |
| `Ctrl-I` | italics, the same way (where the terminal can tell it from `Tab`) |
| `Ctrl-T` | every note and TK in the project |
| `Ctrl-O` | the note for the name at the cursor |
| `Alt-↑` | move the selected scene up; `Alt-↓` down |
| `F2` | start or pause the timer |
| `F3` | reset the timer |
| `F4` | previous track |
| `F5` | play or pause |
| `F6` | next track |
| `F7` | the music player |
| `F8` | spelling suggestions |
| `F9` | themes |
| `F10` | open the menu bar |
| `F11` | show or hide an independent editable document |

## Brain

| Key | Does |
|---|---|
| `n` | start a new note or named page |
| `Enter` | edit the selected note or save the draft |
| `Ctrl-S` | save the draft |
| `Esc` | cancel the draft or open the menu |
| `↑` `↓` | choose a note |
| `→` `←` | open a note's children or go back |
| `p` | open Pages |
| `t` | open Today |

Use Tab to indent a note under the previous note, Shift-Tab to lift it a level,
and Shift-Up or Shift-Down to change its order. Press I to see a note's fields and
links. F edits a field and G defines one on a tag. Type `book / ISBN = text` to
set a field's type, or `book / ISBN -> Book number = text` to rename it.

## Review cards

In Brain, write `front :: back` for a card or `front ::: back` for a
card in each direction. Put `{{words}}` around text you want hidden in
a sentence. For an answer on several lines, write `front ::` and put
each answer line in a child note.

| Key | Does |
|---|---|
| `Enter` or `Space` | reveal the answer |
| `0` through `5` | grade how well you remembered the answer |
| `F` | filter by `#tag` or saved search title. Enter an empty filter for all cards |
| `↑` `↓` | scroll long cards |
| `R` | check for cards that have come due |
| `Esc` | cancel the filter or open the menu |

## The page

| Key | Does |
|---|---|
| `Home` | start of the line; `End` the end |
| `PgUp` | a screenful up; `PgDn` down |
| `Ctrl-C` | copy the selection |
| `Ctrl-X` | cut the selection |

Click to place the cursor, drag to select, and click or right-click an underlined word for its spellings.

## The find bar

| Key | Does |
|---|---|
| `Enter` | the next match (`↓` too); `↑` the one before |
| `Ctrl-R` | replace every match |
| `Ctrl-W` | whole words or inside words (`Alt-W` too) |
| `Ctrl-E` | exact case or any case (`Alt-C` too) |

`Tab` moves between the find and replace boxes.

## Help

| Key | Does |
|---|---|
| `↑` `↓` | choose a topic; in an article, scroll a line (`j` `k` too) |
| `Enter` | read it; `→` and `Tab` too |
| `PgDn` | scroll the article; `PgUp`, `Home` and `End` too, and `Space` inside it |
| `←` | back to the topics; `h` too |
| `F1` | close the help |

Type to search every topic. `Esc` clears the search, then closes the help. In a narrow window the article has the whole box, and `Esc` steps back from it to the topics first.

## Writing journal (WrOS)

Open Writing journal in Ctrl-K or Tools › Notes › Writing journal…. These are modal reader controls, never ordinary editor letter remappings.

| Key | Action |
| --- | --- |
| Left / Right, t | Previous / next local date, today |
| Tab | Recorded facts / original reflection preview |
| Up / Down, PgUp / PgDn, Home / End | Scroll reader only |
| c | Current clean saved snapshot after real manuscript work; not a gross/time estimate |
| Enter / e | Explicit original reflection editor in Secondary / Primary |
| r | Explicitly reload/retry pending facts without replacing recorded observations |
| Esc | Leave reader |

Bracketed/clipboard paste in the reader is ignored. Known unavailable/non-UTF-8 manuscript totals are not fabricated, and note-only saves are not manuscript-writing events. See Writing journal help for sampled-checkpoint limits and force-exit warnings.

## Scratchpad, handoff and explicit starters (WrOS)

Ctrl-K remains reachable from read-only Pinboard, Writing journal, Scratchpad and Session handoff, as well as ordinary writing. Reader prose/clipboard paste never executes letter commands.

| Key | Action |
| --- | --- |
| Scratchpad n / N, Enter / e | New original / edit original in Secondary or Primary |
| Scratchpad l / g | Link a manuscript scene / open its original |
| Scratchpad p / v / x | Promote independent saved snapshot / view original scene / cancel unwritten preparation |
| Scratchpad Tab, a / Delete | Lifecycle views, archive/restore or Trash reference only |
| Handoff s / g / o | Save and arm next open / resume context / toggle startup display |
| Readers PgUp / PgDn, Home / End | Independent preview scroll |
| Readers r / Esc | Explicit reload / leave |
| Workspaces b / p | Explicit starter preset / per-workspace pin set |
| Pin set Space, a / z | Toggle card, select all / none (draft until saved) |
| Pin set Enter / A / Esc | Save explicit IDs / follow all future cards / cancel |

Preset application is explicit, empty-source-only, owner-aware and guarded by clean source saves/current layout metadata. Existing Markdown/YAML is never templated over. Promotion preserves the original note; its new scene is independent, not a live synchronized copy. Handoff is manually authored prose, not generated advice, measured session time or backup.
