# Prose and revision dashboard

Open **Prose and revision dashboard** from Writing tools or the command palette. Opening this reader does not start analysis, grant model permission or edit the source. It owns no second editor. F1 explains the current reader and returns to it with Escape.

## Explicit current-source analysis

- **r** runs local native patterns, independent dictionary spelling and the pinned standalone proselint adapter. Missing Python data is reported, never downloaded or treated as an empty clean check.
- **p** cycles the shared, persisted Drafting, Revision and DeepReview profile. Drafting suppresses style interruptions; broader profiles give advisory patterns, not universal errors.
- **f** selects persisted General, Accessible or Experimental fiction guidance. Experimental does not prescribe a sentence-length limit. **l** controls dialogue-style relaxation; dialogue remains prose and usage is not suppressed wholesale. **o** explicitly includes/excludes footnotes.
- **g** from the summary opens the separate Harper reader and its own permission controls. Only a validated same-editor/current-policy Harper cache can join this queue. An absent cache is shown as not run, not a grammar pass.
- **Enter** reviews actual statistics and opens the ranked queue. Tab cycles Open, All, Grammar/Usage, Spelling, Style, Readability and Reviewed filters. Priority is workflow order, not a literary score.

Native analysis words, unique normalized words, heuristic sentence segments, approximate syllables, rhythm and punctuation are descriptive approximations, **not** native goal/ledger word units or measured writing activity. The approximate English grade requires at least 100 analysis words and three segments; it is unreliable for some names, poetry and multilingual prose. Readability is not literary quality, reader ability or authorship evidence.

## Optional Nabokov model

**d** discloses the optional trained spaCy pipeline; **y** permits exactly one run on the current opted-in source/configuration. Harper permission does not grant this permission. No live Nabokov permission is saved. Missing, failed, cancelled or oversized work is reported, not called clean.

The adapter pins Nabokov 26.7.10 at source e6f98ce64b52, spaCy 3.8.16 and en_core_web_sm 3.8.0; proselint pins 0.16.0 at dbed789caae6. The Python worker verifies exact versions and critical package/model file-tree hashes, uses no file-config discovery or runtime downloads, blocks ordinary socket connections and receives only the bounded masked projection over a local pipe. This is defense in depth, not a complete malicious-code sandbox or legal/security certification. NB5xx detector and NB7xx authorship/profile scoring rules are never enabled or accepted.

Each explicit job has a 65,536-byte source budget, 256 findings per service and 512 ranked queue items. The child has a 30-second CPU and 60-second wall budget; one active worker and one coalesced newest request keep input/rendering independent. The child exits after the run rather than retaining a model process. Rendering uses cached results only. These bounds are not physical latency, energy or battery certification.

Completed current queue findings underline the existing original-source editor. Escape closes the reader and cancels unpublished work, but retains a completed current cache. Any edit, Undo, source owner or policy change immediately hides stale marks. **c** on the summary explicitly clears the cached results/marks and cancels pending prose work; independent spelling and Harper controls are unchanged. No live Python model process is retained. The Linux amd64 worker also fails closed if its no-new-privileges, syscall-level socket/io_uring/child-exec denial cannot be installed. This is not a complete filesystem sandbox or independent security qualification.

## Review and original-source edits

Select a finding and Enter to inspect its engine, exact version, rule, source UTF-8 byte range, context, original selection preview and all equivalent-rule provenance. Unrelated overlapping findings are retained.

- **g** in a detail selects the existing original source. **s** there opens the existing spelling suggestions at that word; dictionary alternatives are not generated for every queue row.
- Left/Right selects a literal alternative. **a** explicitly performs one source-checked native Replace; it never applies a rewrite direction or automatically advances through fixes. Escape returns to native Undo. Replacement is not typing credit.
- No replacement may cross source markup/escapes, unresolved disk conflicts, editor owners, revisions or settings. Even Undo restoring identical bytes changes the editor version. Stale results are hidden/discarded; refresh with r.
- **i** ignores this occurrence for this run. **m** mutes the primary version-bound rule for this novel; **M**, then y, explicitly mutes personally. A dictionary-rule mute is broad; prefer native spelling's add-word action for one intentional name.
- **w** saves a Reviewed receipt; **x** saves Dismissed. These guarded records contain document/hash/rule/range references, never manuscript paragraphs. A new source, policy or engine version is not automatically reviewed. Corrupt, future or externally changed metadata is preserved and reported.

## Selected-reference voice

**v** opens frozen voice references; **n** lets you explicitly select your own saved original manuscript sources. Space toggles a source; Enter names the reference and prepares statistics off-thread. No automatic whole-book or research sampling occurs.

A baseline needs at least **5,000 analysis words, 40 sentence segments and one source with 150 distinct normalized words**, with one to 64 nonduplicated sources. These are minimum material gates, not proof of representativeness, quality, ownership or human authorship. A short demo and repeated copies intentionally fail. Save/reconcile unsaved, missing or conflicting originals first.

Review the prepared material counts, then **s** explicitly saves a frozen numeric/reference baseline. It stores source hashes and numeric counts, not a second prose copy or arbitrary manuscript vocabulary. Originals remain authoritative; the baseline never live-rebases. Enter selects a saved profile; D, then y, removes only its metadata without renumbering IDs or deleting sources. Eight profiles are retained; no silent eviction.

Analyze at least **300 current words and five segments**, choose a matching-footnote-scope reference, and use **c** to explicitly review the actual comparison. Feature changes are informational: narrator, scene purpose, genre and form may explain them. There is no overall distance/quality/authorship score and no automatic correction. A profile save or menu visit alone does not complete the comparison exercise.

Lessons 27–30 require actual statistics, an actual returned Nabokov/proselint finding, or a sufficient saved-reference comparison respectively. Merely opening, consenting, queuing, failing or selecting a baseline never substitutes for those postconditions. Original spelling lesson 26 and separate grammar replacement lesson 40 retain their meanings.
