# One-cell drawings WrOS adds to Unifont.
#
# Unifont draws each of these two cells wide, but the interface gives them one.
# Each drawing replaces Unifont's: a header line "U+XXXX" (anything after the
# code point is a comment), then 16 rows of 8 pixels, '#' set and '.' clear.
# Column 7 is left clear so neighbours never touch. Blank lines and lines
# starting with '#' outside a drawing are ignored.
# crates/wros-graphics/build.rs reads this file; its tests check every
# interface symbol against the result.
